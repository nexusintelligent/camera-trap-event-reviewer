ONE-TIME LOCAL SETUP

        
在這台電腦準備辨識器

        
網站介面可由 GitHub Pages 開啟；AI、照片、快取與 CSV 則完全留在你自己的電腦。

      

      
    

    

      
    
        
  1. 1
    第一次使用：安裝本機辨識環境
    在專案資料夾雙擊 安裝照片辨識軟體.cmd。它會自動準備 Node.js、Python 與必要 AI 模型，不需另外安裝或設定 PATH。
    2. 
        
  2. 2
    啟動本機服務
    雙擊 啟動照片辨識軟體.cmd。服務只監聽 127.0.0.1:4173，外部電腦無法讀取你的資料。
    3. 
        
  3. 3
    回到這個頁面並重新連線
    按上方「重新連線」，接著選擇照片或資料夾即可建立獨立工作區。
    4. 
      

      
資料位置照片工作副本、AI 模型與匯出成果會放在 %LOCALAPPDATA%\\CameraTrapReviewer。不同使用者、不同電腦之間不會自動同步。

      
若啟動失敗，請重新執行安裝程式；仍無法啟動時再查看專案內的 logs\\server.stderr.log。
